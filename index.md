# Cosmic Ocean

Welcome to Cosmic Ocean — a small project exploring generative visuals and interactive ocean-like simulations.

## About
Cosmic Ocean is an experimental repository that combines creative code, shaders, and responsive visuals to simulate an oceanic cosmos. This repository contains examples, demos, and documentation to help you run and extend the project.

## Getting started
1. Clone the repo:
   ```
   git clone https://github.com/pratapme1/Cosmic-Ocean.git
   ```
2. Install dependencies (if applicable):
   ```
   npm install
   ```
3. Run the demo:
   ```
   npm start
   ```

- /docs — additional documentation
